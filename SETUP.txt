## Next.js Sales Analytics Portal — Project Structure

This is a full-stack Next.js 14 (App Router) project.
See src/ folder for all application code.

To run this project locally:
  1. Install Node.js from https://nodejs.org (LTS version)
  2. Open terminal in this folder
  3. Run: npm install
  4. Run: npm run dev
  5. Open http://localhost:3000
